# 桃子取回（peach-st-cache）

合格第三方扩展：**仓库根目录就是插件**（含 `manifest.json`）。任何人用酒馆自带的「从 Git / URL 安装扩展」拉取即可；**未安装时，酒馆本体与默认安装里不得有本插件任何痕迹**（不焊进主程序、不预置文件夹、不改酒馆源码）。

断线、超时或浏览器没接到流时，若中转（sub2api）已计费成功，回复在服务端缓存约 **120 秒**。启用本扩展后，聊天页右下角出现桃子悬浮圈；有可取内容时变握拳，点击取回。

## 安装（任何人）

1. 打开酒馆 → 扩展（Extensions）。
2. 使用「Install Extension」「从 Git URL 安装」等入口。
3. 粘贴本仓库的 Git 地址。  
   - 仓库名建议：`peach-st-cache`（安装后文件夹名通常等于地址最后一截）。
4. 在扩展列表启用 **桃子取回**，刷新页面。

卸载 / 禁用后刷新：悬浮圈消失，本扩展脚本不再加载。中转侧接口仍在，但没有扩展标记头就不会写取回缓存。

## 开发源码位置（维护者）

本工作区源码目录：`silly/桃子取回`（与美化、社区同级的**独立插件源**）。  
**禁止**把开发主副本放进 `SillyTavern/public/scripts/extensions/third-party/` 并提交进酒馆本体仓库；那个路径只应出现「用户安装结果」。


## 合格标准自检

- [ ] 空白酒馆（无本文件夹）源码检索不到本插件名
- [ ] 仅 Git 安装后列表出现「桃子取回」，启用后有悬浮圈
- [ ] 删除第三方目录中的本夹并刷新 → 界面与行为恢复，无残留入口
